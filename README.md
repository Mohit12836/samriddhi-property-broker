# समृद्धि प्रॉपर्टीज & रियलिटी (Samriddhi Properties)
## ₹8,000 Premium Indian Real Estate Broker Website

एक आधुनिक, 100% मोबाइल-रिस्पॉन्सिव, लाइट-थीम और हाई-कन्वर्जन रियल एस्टेट ब्रोकर वेबसाइट — विशेष रूप से भारतीय लोकल प्रॉपर्टी डीलर्स के लिए तैयार की गई।

---

### ✨ मुख्य विशेषताएं (Key Highlights)

1. **ब्रांडेड विजुअल डिज़ाइन:**
   - **रनिंग लाइट बॉर्डर (Multi-Color Flowing Light Gradient):** आधुनिक लग्जरी कार्ड्स पर चमकती हुई बॉर्डर जो देखते ही ध्यान खींचती है।
   - **ऑफ-व्हाइट/आइवरी लाइट बैकग्राउंड:** आंखों को सुकून देने वाली क्लीन और प्रीमियम थीम (Navy Charcoal + Royal Gold + Emerald Accents)।
   - **100% फ्लूइड रिस्पॉन्सिव:** 320px मोबाइल से लेकर 1920px+ डेस्कटॉप पर बिना किसी हॉरिजॉन्टल स्क्रॉल के परफेक्ट।

2. **सेंट्रलाइज्ड सिंगल-फाइल कॉन्फ़िगरेशन (`src/config/agency.ts`):**
   - ब्रोकर का नाम, फोन, व्हाट्सएप नंबर, ऑफिस एड्रेस, RERA नंबर, और सर्विस एरियाज — सिर्फ 1 फ़ाइल से पूरा पोर्टल कस्टमाइज़ करें।

3. **वास्तविक डेटा एवं 100% वर्किंग व्हाट्सएप लीड इंजन:**
   - हर प्रॉपर्टी के लिए डीप-लिंक्ड ऑटो-प्रीफिल्ड व्हाट्सएप मैसेज (Property ID, Title, Locality और Price सहित)।
   - ओनर प्रॉपर्टी सबमिशन पोर्टल (`/sell`) सीधे व्हाट्सएप पर लीड भेजता है।
   - कोई डेटाबेस या पेड API का झंझट नहीं — ज़ीरो मंथली खर्च।

4. **लाइव फ़िल्टरिंग एवं खोज डायरेक्टरी (`/properties`):**
   - सेल, रेंट और प्लॉट्स के लिए इंस्टेंट टैब्स।
   - बजट-आधारित ब्राउज़िंग (Under ₹15 Lakh से लेकर ₹1 Crore+)।
   - लोकैलिटी और प्रॉपर्टी टाइप अनुसार रियल-टाइम फ़िल्टर।
   - सॉर्टिंग (Price Low-to-High, High-to-Low, Newest)।

5. **संपूर्ण पेज संरचना:**
   - `/` - 12-सेक्शन होमपेज (हीरो, कैटेगरीज, 6 फीचर्ड कार्ड्स, बजट ग्रिड, लोकैलिटीज, व्हाई चूज अस, मीट ब्रोकर, सेल सीटीए, एफएक्यू, फुटर)।
   - `/properties` - ऑल प्रॉपर्टीज फ़िल्टर कैटलॉग।
   - `/properties/[slug]` - इंडिविजुअल प्रॉपर्टी डिटेल पेज विथ गैलरी, हाईलाइट्स और स्टिकी इन्क्वायरी बॉक्स।
   - `/sell` - प्रॉपर्टी ओनर सबमिशन गाइड।
   - `/about` - ब्रोकर परिचय एवं मूल्य।
   - `/contact` - ऑफिस एड्रेस, फोन, मैप्स लिंक।

### 🚀 लोकल में चलाने का तरीका (How to Run Locally)

```bash
# 1. प्रोजेक्ट डायरेक्टरी में जाएं
cd property-broker-website

# 2. डिपेंडेंसीज इंस्टॉल करें (यदि पहले से नहीं है)
npm install

# 3. डेवलपमेंट सर्वर शुरू करें
npm run dev
```

ब्राउज़र में खोलें: `http://localhost:3000`
